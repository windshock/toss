# 43차 세션 핸드오프 (요약 FINDINGS §47)

## 확정
- **QEMU 장치 노드 소거**: /dev/qemu_pipe·goldfish_* 전부 앱 uid ENOENT
  (LKM 차단 정상 — 비트 후보 제외).
- **★ 서버 게이트 판명**: device_id(314872ec…)가 **재설치 불변** — 전 API
  403 블랙리스트가 재설치로 안 풀림. 앱이 [EMULATOR] 콜백 없이 로그인 플로우까지
  진행한 런에서 서버가 전부 차단(파생 식별자 기반). 로컬 목표 D와는 별개
  확인사항.
- **attach 0.8s = 가드 흐름 변화**(콜백 소멸) — mask 관측은 2.0s 고정.
- **mask 캡처 변동성**: 동일 조건에서도 포착 ~1/5(스캔/폴링 레이스) —
  상태당 ≥3런 샘플링 프로토콜 필요.
- **환경 피로**: 연속 실험 후 frida attach 거부 발생 — 재부팅으로 리셋 필요.

## 44차 순서
1. 게스트 재부팅 → boot_recover → apply_37→38→40→41 체인 → 상태 검증.
2. mask 기준선 ≥3샘플(2.0s attach) → 0xBE 확인 → mask-diff 개시
   (센서 값 → IMEI → 배터리 순, 1입력씩, 상태당 3런).
3. (선택) android_id 리셋으로 서버 게이트 재시험.
4. 9/25 claude 리셋 후 통합 검토.
