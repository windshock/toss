# HANDOFF — 카모33 잔여 과제 (2026-09-29, S125 인계)

> 전제 지식: FINDINGS §114~§124 (살성 체인 폐쇄·guardLevel 게이트·스캐너 폴라리티·fds=[EMULATOR] 단독).
> 결론 상태: "EMULATOR 비트 입력 = 구조적"은 **강한 추론** — 아래 Task A가 이를 측정으로 승격 or 반전시키는
> 마지막 작업이다. 다른 세션(§65 8접근)에서 OLLVM 정적 RE는 막혔고, §14-5① 차분 캡처는 미실행 종료.

## 환경 규칙 (반드시 먼저)
- **camo33과 랩 VM을 동시에 돌리지 말 것** — 호스트 스왑 포화(25.7GB/26.6GB)로 게스트 패닉급 스팸
  ("Bad swap file entry") → 앱 오탐(HOOK) 유발 실측됨(§122). 랩 작업 시 camo33 종료, 그 역도.
- camo33 부팅 실패 시: 크래시 리포트 동의 다이얼로그 확인 → `rm -rf /tmp/android-1004276/emu-crash-*.db`
  후 재기동(§122). 부팅 후 `boot_recover.sh 10178` (ANDROID_SERIAL=emulator-5554 필요).
- 랩 부팅: `analysis-lab/android/scripts/boot_lab.sh` (~3분) + `adb connect localhost:5555` +
  `su 0 nohup /data/local/tmp/frida-server >/dev/null 2>&1 &` (root 확인 — non-root면 spawn이
  "jailed" 오류).
- 측정 원칙: 프리다/후킹 없는 최종 상태가 목표. 계측은 랩에서만. 하나의 변수만.

## Task A (최고 가치) — 서브체크 fn ptr + w0 전수 캡처 → EMULATOR 입력 채널 측정
- **목표**: libea56 체크 배터리의 각 서브체크가 무엇을 보고 무엇을 반환하는지 실측. "구조적 신호" 가설을
  측정으로 전환하거나 스푸핑 가능 입력을 발굴.
- **대상 구조 (§14-4 확정분)**:
  - 디스패치 루프 `libea56+0xa021c..0xa0488` (2단 테이블 `#0x960`/`#0x8` → `blr x8` 서브체크 → `cmp w0,#0`)
  - 체크 노드 링크드리스트 `0xa4038` (`blr x9; str w0,[x20,#0x38]; ldr x20,[x20,#0x28]`)
  - 경로상 문자열 복호 루프 `97a2c/9e728/a7448/ac43c`, 비교 예 `ac470 cmp w10,#0x2`
- **어디서**: 랩 (redroid). 동일 libea56 (sha256 c454eb40…6203b89) — camo33 오프셋 그대로 유효(§98).
- **방법 (2안)**:
  - (a) gdbstub HW bp (검증 프리미티브: `scripts/re-lab.py hwbp`, `hvf_hwbreak_toy.py`, §93~§97).
    루프 엔트리 `0xa021c` bp → x8(서브체크 ptr)·반환 w0 기록. **경량 원칙**(§101: 무거운 bp는 경로 소멸).
    afed8 census로 경로 생존 확인하며.
  - (b) frida + Interceptor.attach를 서브체크 trampoline에 (LKM 없는 랩이라 가능). §119 harvest 스타일.
- **성공 기준**: 실패(w0≠0) 서브체크 목록 + 각 주소의 정적 판독(llvm-objdump, VA==file offset, §14-5 도구)으로
  입력 채널 확정. 기대 후보군: goldfish open-성공(GL 결합) / QEMU 디바이스 / CPU 거동 / 센서 HAL / 미발견 채널.
- **주의**: 개별 서브체크 함수가 작아 OLLVM이어도 개별 판독은 가능할 수 있음(§65의 벽은 "전면" 디옵스였음).
  Death-vs-survive 차분 불요 — 사망 런에서 전수 기록이면 충분(§14-6의 "생존 재현" 전제 폐기).

## Task B — R-틱 자유실행 발화 여부 (camo33, 프리다 없음)
- **목표**: Java-exit을 억제한 채 자유실행 시 첫 스캐너 틱(§124: 킬=첫 틱 1회)이 자폭으로 가는지.
  §123의 "② 자연 통과" 가설 검증.
- **방법**: hide_kmod에 exit_group 지연/파킹(monimo crash-avoidance 선례, v3.6.6) — toss uid만. LKM
  rebuild는 `lkm/build-in-docker.sh`. → 5s exit 억제 → 20s+ 관측.
- **판정**: (a) SIGSEGV 없이 생존 → R-틱 무해/미발화, GOAL 잔여 = EMULATOR 비트만. (b) ~20s SIGSEGV
  (tombstone lr=pc=0xc, x29=0x24) → 실재 → Task C로.
- **관측**: 하니스 `trace_run.sh --fresh` + tombstone + am_proc_died 타임라인. logstore flush 전 사망
  오독 주의(§74 교훈 — 반드시 스냅샷/merged로).
